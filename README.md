# 法医昆虫学样品记录工具

现场按案件登记采样批次、采样点与环境温度；实验室在同一条记录上补录昆虫种属、发育阶段与鉴定结论。
传感器数据允许乱序到达、允许断档；断网时全部变更先落本机，联网后按时间戳合并。
温度记录每次改动，积温与虫龄结论立即重算；已定稿的鉴定不可被替换，只在其依据发生变化时标注"已过时"。

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 按案件登记批次 / 采样点 / 现场温度 | "案件"页登记案件、采样点、批次（含保存方式、采集人、现场环境温度） |
| 暴露阶段与昆虫种属由实验室鉴定 | 批次详情"实验室鉴定"：草稿可反复改；种属与积温参数在"参数与合并"页校准 |
| 传感器读数乱序 / 断档 | 读数带"到达时刻"，乱序自动重排并提示；同时刻重复取均值；相邻间隔超过断档阈值（默认 90 分钟）的时段**不积分**，曲线画为虚线并降低覆盖率 |
| 断网先记本地、联网再合并 | 全部写入先进 IndexedDB 再进发件箱；离线只积压，联网自动推送。中继用同浏览器 `localStorage` + `BroadcastChannel` 模拟，**开两个标签页即可验证多端合并**；删除以墓碑同步 |
| 温度改动 → 积温重算 | 积温为纯函数、随渲染实时重算：梯形法有效积温（ADH）、覆盖率、均温、虫龄区间、定植窗口 |
| 定稿不可替换、但看得出过时 | 定稿文档客户端与中继双重写保护；定稿保存温度哈希与参数快照，任一变化即在列表/详情/案件页显示红色"定稿已过时"，并可基于定稿新建修订版（原结论进入版本链保留） |
| 批次按发育阶段筛选 | 批次列表左侧：卵 / 各龄幼虫 / 离食 / 蛹 / 成虫 / 未鉴定，附案件过滤与关键词检索 |
| 详情卡看温度过程 | 批次详情：SVG 温度曲线（断档虚线、采样时刻竖线、采样后读数只展示不积分）、读数明细表、CSV 导入/导出 |
| 照片 | 每批次可附一张样本照片，**只存本机 IndexedDB，明确不参与联网合并**（笔录数据正常合并） |

积温算法说明（`src/domain/thermal.ts`，均为纯函数）：

- 有效积温 ADH = Σ 有效段梯形面积，有效温度 = max(温度, 起点温度) − 起点温度；
- 断档段剔除，覆盖率 = 有效积分时长 / 观测窗口；
- 虫龄：从采样时刻沿累计 ADH 曲线回溯 `阶段目标 ADH`，线性插值；覆盖率不足时年龄上界放宽缺失时长；观测积温不足时按平均积温速率外推并明确标注"外推，仅供参考"。

> 种属积温常数（起点温度、各阶段目标 ADH）为教学演示参考值，正式案件应以本实验室标定品系数据为准，可在"参数与合并"页校准。

## 技术栈

React 19 + Vite + TypeScript，无后端；IndexedDB 本地库 + 发件箱，localStorage/BroadcastChannel 模拟服务端中继。

## 运行

```bash
npm install
npm run dev      # http://localhost:62003
```

## 验证

```bash
npm test         # 11 项积温/合并单测 + 9 项端到端冒烟 + 4 项 React 渲染冒烟
npm run build    # tsc 类型检查 + Vite 构建
```

内置演示数据刻意包含：乱序晚到读数、同时刻重复读数、4 小时断档、一条"定稿后次日补录的夜间温度"——
打开后批次 `091-A01` 即为"定稿已过时"状态；把读数 `batch-1-rlate` 删除，过时标记会随重算自动消失。
"参数与合并"页可一键重置全部演示数据。

### 多端合并验证步骤

1. 开两个浏览器标签页都打开本应用；
2. 在 A 标签页"参数与合并"里切到**离线**，改一条批次备注并补一条温度（顶部出现待合并计数）；
3. 在 B 标签页观察不到变化（此时 A 的变更只在本机）；
4. A 切回**在线** → 发件箱自动推送，B 收到广播后自动拉取合并；
5. 尝试编辑已定稿鉴定：入口被禁用，直接改存储层也会被中继拒收并回滚。
